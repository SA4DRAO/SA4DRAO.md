## 🔭 What I'm building

I focus on the **systems layer of AI** — the parts that turn a demo agent into something you can
actually ship and trust:

- **LLM Observability** — tracing, evaluation, and audit for agent workloads without vendor lock-in.
- **Agent Memory** — graph + vector memory so agents remember context across turns and sessions.
- **Self-hosted AI infrastructure** — open, portable stacks you own, not a black-box SaaS.
